# TEO-hallintajärjestelmä

Projektin tavoitteena on opetella käyttäjälähtöistä suunnittelua käyttäjätarinoiden avulla, tietomallinnusta, ER-kaavion suunnittelua, SQL-kyselyt sekä javascript olio-ohjlemointia. Tämä on koulu harjoitus.

## Proejktin tarkoitus

Järjestelmän tarkoitus on toimia oppilaitoksen työssäoppimis jaksojen hallintajärjestelmänä.
Järjestelmän avulla voidaa:

- tallentaa opiskelijoiden tiedot
- hallita työpaikkoja
- hallita työpaikkaohjaajia
- luoda TEO-jaksoja
- suunnitella näyttöjä
- tallentaa arviointeja
- seurata opiskelijoiden etenemistä.

## käytetyt teknologiat

- MariaDB / MySQL
- Javascript
- PHP
- HTML
